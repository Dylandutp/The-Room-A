# The Room A

CS417 Unity VR project: a bright computer lab and a nature area with a planet, moon, gravitational projectiles, interactive panels, particles, and spatial audio.

## Open the project

- Unity Editor: 6000.5.6f1.
- Install Git LFS before cloning, then run `git lfs pull`.
- Open this repository in Unity Hub and load `Assets/TheRoom/Scenes/TheRoom.unity`.
- Android/Meta Quest builds require Android Build Support and the project's OpenXR settings.

## Assets

Third-party audio licenses and source links are included with the audio assets. Course-provided materials and Unity sample assets retain their respective terms.

Local recovery snapshots, generated previews, Unity caches and build outputs are excluded from the current project tree.
